# 🤖 Multi-Agent AI Coach

DailyForge features an autonomous multi-agent fleet where user prompts and system events are routed to specialized sub-agents based on context.

---

## 👥 Specialized Agent Fleet

### 1. `HabitCoach`
- **Domain**: Atomic routine design, 2-minute rule adaptations, habit stacking.
- **Trigger**: Routine friction, initiation resistance, new habit creation.

### 2. `PlannerOptimizer`
- **Domain**: Circadian schedule alignment, focus block durations, overload prevention.
- **Trigger**: Calendar conflicts, overloaded capacity, auto-schedule requests.

### 3. `GoalStrategist`
- **Domain**: High-impact roadmap decomposition, milestone weighting, velocity analysis.
- **Trigger**: Behind-schedule goals, new milestone planning.

### 4. `MomentumAnalyst`
- **Domain**: 5-pillar Forge Score decomposition, weekly recovery trends, trend narration.
- **Trigger**: End of Day Momentum Reviews, analytics drilldowns.

### 5. `RecoveryCoach`
- **Domain**: Cognitive fatigue management, streak recovery without shame, cognitive resets.
- **Trigger**: Consecutive habit misses, low energy check-in logs.

### 6. `ExperimentScientist`
- **Domain**: N-of-1 scientific hypothesis generation and intervention trial design.
- **Trigger**: Routine optimization inquiries, Forge Lab builder requests.
