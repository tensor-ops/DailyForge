# ⚡ Recommendation Engine & 1-Click Actions

The DailyForge Recommendation Engine bridges data insights with immediate execution by proposing structured, 1-click schedule interventions.

---

## 🎯 Recommendation Lifecycle

```text
Behavior Telemetry → Pattern Detected → Recommendation Created → User Reviews Proposal → 1-Click Apply → Planner / Habit Updated
```

---

## 🛠️ Supported Automated Actions

1. **`SHIFT_HABIT_TIME`**: Moves a habit to a statistically superior time window (e.g. from 02:00 PM to 07:30 PM).
2. **`SPLIT_FOCUS_SESSION`**: Breaks a high-friction 90-minute block into two 45-minute Pomodoro intervals.
3. **`RESCHEDULE_OVERLOADED_DAY`**: Defers low-priority tasks when planned commitments exceed daily capacity.
4. **`APPLY_EXPERIMENT_OUTCOME`**: Adopts the successful intervention schedule into recurring planner rules.
